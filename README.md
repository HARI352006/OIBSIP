## ⚙️ Getting Started

### Prerequisites

Before running these projects, ensure that you have:

- Java Development Kit (JDK) installed
- A Java-compatible IDE, such as IntelliJ IDEA, Eclipse, or VS Code
- Git installed if you want to clone the repository

Verify your Java installation:

```bash
java -version
javac -version
```

### Clone the Repository

```bash
git clone https://github.com/HARI352006/OIBSIP.git
```

Navigate to the Java Development folder:

```bash
cd OIBSIP
cd "Java Development"
```

### Run a Project

1. Open the required task folder.
2. Locate the main Java source file.
3. Open a terminal in the appropriate source directory.
4. Compile the Java file using `javac`.
5. Run the program using `java`.

Example for a single-file Java application:

```bash
javac Main.java
java Main
```

Replace `Main.java` and `Main` with the actual source filename and class name. Projects containing multiple files or packages may require a different command.
