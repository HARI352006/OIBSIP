# 🏧 ATM Interface System

A Java-based **ATM Interface System** developed as part of the **Oasis Infobyte (OIBSIP) Java Development Internship – Task 3**.

## 📌 About the Project

The ATM Interface System is a Java application that simulates the basic operations of an Automated Teller Machine (ATM). It provides an interactive way to perform banking-related operations, such as checking account balance, depositing money, withdrawing cash, and viewing transaction details, depending on the features implemented.

This project demonstrates the practical application of Java programming concepts, object-oriented programming, conditional statements, methods, and input handling.

## ✨ Features

- 🔐 **User Authentication** — Validates user credentials, if implemented.
- 💰 **Balance Inquiry** — Displays the available account balance.
- 💵 **Cash Deposit** — Adds money to the account balance.
- 💸 **Cash Withdrawal** — Withdraws money after checking available funds.
- 📜 **Transaction History** — Displays previous transactions, if implemented.
- 🔄 **Money Transfer** — Transfers funds between accounts, if implemented.
- 🚪 **Exit Option** — Allows the user to exit the application.
- ⚠️ **Input Validation** — Handles invalid choices and transaction amounts, where implemented.
