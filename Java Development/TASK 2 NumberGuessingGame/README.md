# 🎯 Number Guessing Game

A simple and interactive **Number Guessing Game built using Java**, developed as part of the **Oasis Infobyte (OIBSIP) Java Development Internship – Task 2**.

## 📌 About the Project

The Number Guessing Game is a Java application in which the computer generates a random number, and the player attempts to guess it correctly. The game provides hints after each guess to help the player determine whether the secret number is higher or lower than the entered value.

This project demonstrates fundamental Java programming concepts, including random number generation, loops, conditional statements, user input handling, and logical problem-solving.

## ✨ Features

- 🎲 **Random Number Generation** — Generates a secret number for the player to guess.
- 🔢 **User Input** — Accepts guesses from the player.
- 💡 **Helpful Hints** — Indicates whether the guessed number is too high or too low.
- 🎮 **Interactive Gameplay** — Continues the game according to the implemented rules.
- 🏆 **Win Detection** — Identifies when the player guesses the correct number.
- 🔄 **Replay Option** — Allows another round if implemented in the source code.

## 🎮 How to Play

1. Start the application.
2. Read the instructions displayed by the game.
3. Enter a number within the specified range.
4. Check the hint provided after each guess.
5. Adjust your next guess based on the hint.
6. Continue until you guess the correct number or reach the game's attempt limit.

The exact range, attempt limit, scoring system, and replay options depend on the implementation.
